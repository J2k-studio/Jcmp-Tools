# The tools of ex-pkg: NAME|what it is
jget|Download files from the web (https, a progress bar), and the libraries of the J2K language
jurl|Get things from the web: jurl LINK saves the file; commands written for curl work (-fsSL, -LO, -I, -d), https
makej|A build tool for J2K projects: the build file is a plain file (nano makej) or a J2K program
jx86|An x86_64 emulator for Linux programs (static ELF): run and measure x86 code on any machine
jsh|A small shell for J2K machines: line editing, ghost text, pipes, variables, aliases, scripts
jbox|The basic commands in one program (dir cat cp mv rm mkdir grep sort ...); installs links so every shell finds them
jpty|Run a program on a pseudo terminal, driven through two pipes (for apps and tools)
fcode|A code editor for the terminal (colours, select, copy and paste, find)
ex|The commands of the system: ex install, update, search, run, the settings of the app
ascode|An assistant in a folder (Claude): reads, edits and runs with a y before a change
jex|The command of the language: fetch libraries, update the compiler (jex lib install NAME)
jene|Make and run games with jex: jene -c NAME, -b, -rc
jcmp|The compiler of Jex (ex install jexcmp: with jex and every library)
apkj|Builds an Android apk of a J2K app with no Android tools (zip, binary manifest, signing); makej apk uses it
zipj|Make and open zip files (zipj, unj): folders, a password, deflate, also .gz
tarj|Make and open tar archives (.tar, .tar.gz, .tgz) and gzip files (tarj, gzj)
imgj|Prepare pictures for a game: read PNG and JPEG, cut the background, real size, parts, normal maps, credits
authj|One-time codes for two-step logins (TOTP like Google Authenticator) for GitHub and other sites; a vault locked with a passphrase
jrawser|Jrawser, the browser of the Jaric app: tabs, bookmarks, history, downloads (the system WebView in a window)
mulap|Record songs and make beats: a plan of a beat becomes a sound file (the engine; pads and recording come next)
jearlink|The apps of the phone from the terminal: open links, share, install an apk (-ins), call, start apps, notifications (-viw -snd -sh -cll -ap -aps -ntf)
cam|The camera of the phone for the Jaric app terminal: photos and reading QR codes
mujic|A music player for the terminal: your songs, free songs to fetch, synced lyrics (mujic)
jvp4|A video player made only of J2K (today: jvp4 info reads mp4 / mov files)
yt-dlp|Downloads audio and video from many sites with yt-dlp (needs the tool python); use it only for what you may download
jash|The settings of your programs in one file (~/.jash) and the command to read and change it (jash list, get, set, edit, import)
neuron|Small AI models on the phone: train a GPT (attention) or a small model on your text, chat with it, run GGUF models, the assistant xaiorin (xr)
jgit|git written in J2K: init, add, commit, status, log, diff, branch, switch; the repositories are the repositories of git, also packed ones clone (--depth 1), fetch, pull, push over https
drive|New drives for Jaric: a new place or a name for a folder (drive, drive new NAME [PATH], drive remove NAME)
calc|A calculator: a screen with keys to tap, or calc "0xff xor 0x0f" (hex, binary, bit operations, functions, variables)

# The tools of Jcmp-Tools: NAME|what it is
jget|Download files from the web (https, a progress bar), and the libraries of the J2K language
makej|A build tool for J2K projects: the build file is a plain file (nano makej) or a J2K program
jsh|A small shell for J2K machines: line editing, ghost text, pipes, variables, aliases, scripts
jbox|The basic commands in one program (dir cat cp mv rm mkdir grep sort ...); installs links so every shell finds them
jpty|Run a program on a pseudo terminal, driven through two pipes (for apps and tools)
coderin|A text editor for the terminal (colours for J2K, select, copy and paste, find)
jcmp|The J2K compiler and its library (the language): jget tool jcmp
zipj|Make and open zip files (zipj, unj): folders, a password, deflate, also .gz
tarj|Make and open tar archives (.tar, .tar.gz, .tgz) and gzip files (tarj, gzj)
mujic|A music player for the terminal: your songs, free songs to fetch, synced lyrics (mujic)
jvp4|A video player made only of J2K (today: jvp4 info reads mp4 / mov files)
python|Python 3.14 for Android ARM64 (the official build, started by a small J2K launcher): python, python3, ssl, sqlite3
yt-dlp|Downloads audio and video from many sites with yt-dlp (needs the tool python); use it only for what you may download
jamanager|The task manager of Jaric: programs, memory, stop a program, drives, caches (jamanager ps, top, mem, kill, drives, cache)
jash|The settings of your programs in one file (~/.jash) and the command to read and change it (jash list, get, set, edit, import)
neuron|Small AI models on the phone: train a language model, chat with it, make it the assistant xaiorin (xr) that runs in the background (.jw files)
jc|Install and run the programs of Jaric (.jc packages) with permissions: jc install, run, list, perm, remove
jstore|The store of the programs of Jaric (.jc): list, install, update with a checksum for every download (needs jc)
jgit|git written in J2K: init, add, commit, status, log, diff, branch, switch; the repositories are the repositories of git, also packed ones (no network yet)
drive|New drives for Jaric: a new place or a name for a folder (drive, drive new NAME [PATH], drive remove NAME)

# Changelog

## 0.5.0
First release as a tool: a teaching game for the learner of computing, English and J2K. Six tracks (computers: the basics, write programs, data structures, the machine and speed, English, jcmp), 52 levels in Thai and English-only, quizzes, a dragon duel with sword moves, formations and a code spell, an exam, XP and ranks, hints, review of missed questions. The levels are built into the program; progress is kept in `~/.learnj` (`LEARNJ_DIR` changes it).

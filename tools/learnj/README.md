# learnj

A game that teaches: computers, English and the J2K language, in tracks you choose. Run `learnj` (`learnj fast` switches off the letters that appear one by one).
Menu: read, quiz, summary, code task (you edit `learn_task.jk`, learnj compiles it with `jcmp` and checks the output), find a word, fight the dragon, review the questions you missed, exam, language (Thai or English only), track.
Progress is kept in `~/.learnj`. Put your own `levels.txt` / `levels_en.txt` there to change the levels (16 fields on a line, separated by a tab; see the repository of learnj).

# คำถามเรื่องการใช้งาน makej (ยังไม่ได้ออกแบบ — ต้นแบบแรกทำไว้ดูว่าไอเดียใช้ได้เท่านั้น) รายละเอียดใน `docs/usage-design.md`
1. **ไฟล์ build**: A) เป็นโปรแกรม J2K (ต้นแบบ, ผมแนะนำเริ่มแบบนี้) / D) ไฟล์ TOML (ทำทีหลังสำหรับโปรเจกต์ง่ายๆ) / ทั้งสอง
2. **คำสั่งที่อยากได้ก่อน**: `list`, `clean`, `-j N`, `init`, `watch`, `install` (ต้นแบบมีแค่ build, ชื่อ target, `-v`)
3. **โฟลเดอร์ผลลัพธ์**: `_out/` ต่อไป หรือ `build/` หรือแยกตาม CPU (`_out/arm64`, `_out/arm32`)
4. **ติดตั้ง makej อย่างไร**: `jget install makej` / มากับ jcmp / ทำเอง
5. **ที่อยู่ของ makej**: repo ของตัวเอง (ตอนนี้) หรือรวมใน Jcmp-Tools
6. **วิธีรู้ว่า "ไม่ต้อง build ใหม่"**: เวลาไฟล์ (ต้นแบบ) หรือ hash ของไฟล์ทั้งหมดที่คอมไพเลอร์อ่าน (แม่นกว่า ผมแนะนำ)
